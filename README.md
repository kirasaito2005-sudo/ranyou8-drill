# 濫用防止8成分ドリル

指定濫用防止医薬品の8成分（エフェドリン、コデイン、ジヒドロコデイン、ジフェンヒドラミン、デキストロメトルファン、プソイドエフェドリン、ブロモバレリル尿素、メチルエフェドリン）と販売ルールを4択で練習できるクイズアプリ。

- 全64問。ランダム10問・成分別・販売ルール・間違えた問題の復習
- 正解／不正解の効果音とBGM（ヘッダーのボタンでオン／オフ）
- 正答率はブラウザ内に保存

`index.html` を開くだけで動きます（外部ライブラリ不要）。

内容は2026年10月時点の制度（令和8年5月1日施行、令和8年厚生労働省告示第32号）と登録販売者試験の手引きの記載に基づいています。
